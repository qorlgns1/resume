## 알려진 제약

- 공개 페이지는 요청마다 렌더링합니다 (`connection()`). 게시 흐름이 생기면 캐시 전략을 정합니다.
- 로그인 시도 제한은 메모리에 저장되므로 어드민 프로세스를 여러 개 띄우면 프로세스마다 따로 셉니다 (단일 서버 전제).
- 실행 중 백업 명령(`VACUUM INTO`)은 아직 없습니다. 지금은 어드민을 멈춘 뒤 `/data`를 복사합니다.
- 공개 API 응답의 `content`에는 전체 라이브러리가 들어 있습니다. 게시 구조를 정할 때 페이지가 참조하는 항목만 담도록 줄일 수 있습니다.
- 모바일 `custom` 순서는 CSS `order`를 쓰므로 스크린 리더의 읽기 순서와 다를 수 있습니다.
- 어드민은 1100px 이상 데스크톱 화면을 기준으로 만들었습니다.
- 스모크 테스트는 31xx 포트를 사용합니다. 그 포트가 이미 쓰이고 있으면 실패합니다.
- Docker 이미지는 Node 24 alpine 기준이며, 크기는 약 300MB입니다 (최적화 전).
